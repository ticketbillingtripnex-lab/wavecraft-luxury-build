# WaveCraft Luxury Build

MGH WaveCraft Premium Website (Simple Architecture)

Create a premium luxury corporate website for:

MGH WaveCraft
Luxury Fiberglass Boat Builders
Maldives

The website should look like it cost over $1,000,000, but the code must be very simple, clean, and easy to edit.

IMPORTANT REQUIREMENTS

This project will be deployed on Vercel.

Do NOT use complicated frameworks or difficult architecture.

Keep everything beginner-friendly.

Use only:

HTML5

CSS3

Vanilla JavaScript (ES6)

Python only if a simple backend is needed (otherwise none)

No database

No authentication

No CMS

No API required

The code should be organized so that a basic developer who knows only HTML, CSS, JavaScript, and Python can easily modify everything.

Avoid unnecessary complexity.
